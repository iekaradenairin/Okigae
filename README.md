# Okigae

Okigae is a WAV/MP3 audio converter for Windows. It will be distributed on the Microsoft Store.

- Download: [latest release](https://github.com/iekaradenairin/Okigae/releases/latest) (portable ZIP). The Microsoft Store version is in preparation.
- Privacy policy: https://iekaradenairin.github.io/Okigae/privacy/
- Questions and bug reports: email iekaradenai.support.rin@gmail.com or open an [issue](https://github.com/iekaradenairin/Okigae/issues).
